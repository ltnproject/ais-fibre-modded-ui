AIS Fibre Modded UI

A beautiful dark glassmorphism skin for the AIS Fibre router admin panel.
Inject it instantly via bookmarklet — no install, no server, no CORS issues.

Open Source GitHub ZTE F6107A · AIS Fibre by LtnProject

How it works

STEP 01
Drag the bookmarklet
Drag the green button below to your browser's bookmarks bar. One-time setup.
STEP 02
Visit your router
Open http://192.168.1.1 while connected to your AIS Fibre Wi-Fi.
STEP 03
Click the bookmarklet
Click it from your bookmarks bar. The router page instantly transforms to dark mode.
STEP 04
Login normally
Session token, captcha, and form submission all work natively — nothing is broken.

Install

Drag to your Bookmarks Bar

Drag the button below to your browser's bookmarks/favorites bar.
Then visit http://192.168.1.1 and click it to activate.

🎨 AIS Fibre Dark Mode
↑

Drag this button up to your bookmarks bar

Can't drag? See the manual install below.  ·  Works on Chrome, Safari, Firefox, Edge.

Manual Bookmarklet Install

Right-click your bookmarks bar → "Add bookmark/page" → paste this as the URL:

javascript:(function(){var s=document.createElement('script');s.src='https://ltnproject.github.io/ais-fibre-modded-ui/inject.js?v='+Date.now();document.body.appendChild(s);})();

Features

🌙
Dark Glassmorphism
Premium dark theme with frosted glass, green glow accents & animated mesh background.
🔑
Native Login
Session token, captcha, and RSA encryption all handled by the router itself. Zero interference.
⚡
Instant Inject
One click. No installation, no browser extension, no backend server required.
👁
Password Toggle
Show/hide password button added to the password field automatically.
📱
Responsive
Works on mobile and desktop browsers.
